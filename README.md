## Technologies Used
- ESP32 and ESP32-CAM
- Ultrasonic sensor (HC-SR04)
- MPU6050 accelerometer and gyroscope
- OLED display and buzzer
- Edge Impulse for object detection
- Embedded C/C++ and hardware integration
